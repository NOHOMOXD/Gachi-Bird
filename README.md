[![itch.io](https://img.shields.io/badge/Play%20on-itch.io-FA5C5C?logo=itchdotio)](https://we-are-gucci.itch.io/gachi-bird)

Ремастер культовой фанатской игры 2018 года, вдохновленной Flappy Bird и феноменом Gachimuchi. Проект полностью переписан с нуля с устаревшего монолитного Canvas 2D кода на современный стек: **TypeScript + PixiJS v8 + Vite**.

---

## 🎮 Особенности ремастера

- ⚡ **PixiJS v8 WebGL/WebGPU Рендер**: Аппаратное ускорение графики с минимальным числом Draw Calls.
- 📐 **Идеальный баланс и физика**:
  - Честные и проходимые препятствия: перепад высоты между трубами ограничен безопасными шагами (~70–90 px), исключая внезапные непроходимые зазоры.
  - Мягкие хитбоксы с внутренними отступами для честного пролета.
  - Независимый от частоты обновления монитора цикл (`delta time`): одинаковая физика на 60 Гц, 120 Гц и 144 Гц.
  - Плавная ротация головы: динамичный наклон вверх при взмахе (-25°) и плавное пикирование носом вниз (+75°) при падении.
- 🎬 **Аутентичные покадровые анимации**:
  - Быстрое покачивание головы Билли (оригинальные 50 FPS / 20 мс на кадр).
  - Анимированный фон с Билли в облаках (плавные 24 кадра из оригинальной гифки, 7.5 FPS для комфортного фона без укачивания).
- 🎨 **100% Canvas UI в аутентичном 8-Bit Ретро стиле**:
  - Полный отказ от внешних HTML div-элементов поверх игры.
  - Стилизованные 8-битные кнопки со ступенчатыми углами и эффектом 3D-нажатия.
  - Натуральная 7-цветная пиксельная радуга (Каждый Охотник Желает Знать Где Сидит Фазан) с пиксельными облаками.
  - Интерактивное главное меню, экран настроек со слайдерами громкости, мемориал Билли Херрингтона и карточка Game Over с анимацией тряски экрана.
- 📱 **Адаптивный ресайз для любого экрана и itch.io**:
  - Пропорциональный Letterbox (9:16) с центрированием в окне браузера или iframe.
  - Встроенная кнопка перехода в полноэкранный режим (**Fullscreen**).
- 🔊 **Оптимизированное аудио и обход ограничений браузера**:
  - Полная предзагрузка музыки и звуков в лоадере (исключены микрофризы и задержки во время игры).
  - Кнопка «CLICK TO ENTER» сразу разблокирует Web Audio: тема Титаника играет в главном меню с первого момента.
  - Кнопка быстрого отключения звука (Mute) в верхнем баре.
- 📦 **Единый Texture Atlas**: Все текстуры упакованы в легковесный спрайтшит (300 КБ), собираемый автоматически скриптом `sharp`.

## 🚀 Локальный запуск и разработка

Требования: [Node.js](https://nodejs.org/) (версия 18+).

```bash
# 1. Клонировать репозиторий
git clone https://github.com/NOHOMOXD/Gachi-Bird.git
cd Gachi-Bird

# 2. Установить зависимости
npm install

# 3. Запустить сервер разработки
npm run dev

# 4. Сборка продакшн-версии (в папку dist/)
npm run build

# 5. Просмотр готовой сборки
npm run preview
```
